# Images

Place approved website images in this folder.

Suggested files later:

- `instructor.jpg`: a photo of [MUM_NAME], if she wants one used.
- `class-photo.jpg`: an approved class photo, only if everyone visible has agreed.

Before publishing:

- Do not use photos of class members without permission.
- Update image `alt` text in `index.html` to describe the real image.
- Keep image file sizes small so the site loads quickly.
