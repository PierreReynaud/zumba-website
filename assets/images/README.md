# Images

Place approved website images in this folder.

## Current selections

- `mum-work-selection/web-ready/`: optimised session photographs supplied for review. The page uses a small, varied selection rather than the complete set.
- `online/undraw-personal-training.svg`: free unDraw artwork used to communicate guided learning. It is illustrative only and does not show a hypopressive position.
- `online/pexels-thirdman-breathing-pause.jpg`: free Pexels stock photograph used beside the symptom-awareness signpost. It is a calm, illustrative image rather than a demonstration of the method.
- `online/openstax-pelvic-floor-muscles.jpg`: OpenStax Anatomy and Physiology pelvic-floor diagram, reused from Wikimedia Commons under CC BY 4.0. It is a general anatomy reference, not a diagnosis or an exercise instruction.

See [`ASSET-SOURCES.md`](../../ASSET-SOURCES.md) for source pages, creators and licence notes.

Suggested files later:

- `instructor.jpg`: an approved instructor photo, if the instructor wants one used.
- `session-photo.jpg`: an approved hypopressive training photo, only if everyone visible has agreed.

Before publishing:

- Do not use photos of clients or class members without permission.
- Update image alternative text in `index.html` to describe the real image.
- Keep image file sizes small so the site loads quickly.
- Confirm that external source pages and licence terms are still current.
- Do not imply that a stock model, illustrator or anatomy source endorses the training service.
- Confirm that sourced anatomy remains understandable with the adjacent HTML text and in forced-colour mode.
